# Issue tracker: none

This repo does not use an issue tracker.

## When a skill says "publish to the issue tracker"

Don't create an issue or a file. Present the result in the conversation, or ask the user where to write it if they want to keep it.

## When a skill says "fetch the relevant ticket"

There is none. Ask the user to describe the task or paste it.

## Wayfinding operations

Used by `/wayfinder`: without a tracker there is no map or child tickets to read or write. Keep the map and its notes in the conversation, or ask the user for a file to hold them.
